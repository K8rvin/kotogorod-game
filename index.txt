Проект «Котогорода» перенесён в Cocos Creator 3.8.8. Исходный пульт баланса больше не используется как игровая страница: его значения легли в основу экономики.

Исходники игры находятся в assets/scripts, сцена — assets/scenes/main.scene, ресурсы — assets/resources. Папка src содержит временный переносимый прототип, который удаляется после проверки Cocos-версии.

Команды:
- npm run dev — открыть проект в Cocos Creator;
- npm run build — собрать Web Mobile в build/web-mobile;
- npm run typecheck — проверить TypeScript с декларациями установленного Creator.

Редактор распаковывается в служебную папку .cache/cocos/editor и не входит в сборку. Яндекс SDK и реклама на этом этапе намеренно не подключаются.
