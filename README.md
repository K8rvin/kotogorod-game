# Котогород

Атмосферная merge-игра о восстановлении дождливого города и его пушистых жителей. Игрок объединяет предметы, выполняет просьбы котов, тратит звёзды на реставрацию районов и постепенно возвращает городу свет.

Проект создан на **TypeScript + Cocos Creator 3.8.8**. Основная игровая версия находится в `assets/`; каталог `src/` содержит ранний справочный прототип.

## Игровые возможности

- Слияние трёх одинаковых предметов и выгодное слияние пяти.
- Шесть цепочек предметов, заказы, энергия, опыт, монеты, звёзды и ключи.
- 12 авторских сюжетных глав и бесконечные процедурные ночные истории.
- Реставрация районов, коллекция из 18 персонажей и 20 достижений.
- Сундуки, ежедневные награды, сумка, перетасовка и усилители.
- Четыре дополнительных режима:
  - **Кошачьи сны** — цель и ограниченное число ходов.
  - **Экспресс уюта** — трёхминутный забег на очки.
  - **Ночное дежурство** — бесконечные заказы с растущей сложностью.
  - **Фестиваль огней** — три последовательных этапа с особыми наградами.
- Звуки и фоновая музыка, регулировка громкости и режим уменьшенной анимации.
- Автоматическое локальное сохранение с резервной копией.

## Управление

- **Перетаскивание:** перенесите предмет на другой, чтобы переместить или объединить его.
- **Два нажатия:** последовательно выберите два предмета как альтернатива перетаскиванию.
- **Генераторы:** создают новые предметы за энергию; в дополнительных режимах действуют их собственные правила.
- **Усилители и сумка:** выберите предмет на доске, затем откройте `Ещё → Сумка и усилители`.

## Запуск проекта

### Требования

- Node.js с поддержкой современного JavaScript.
- Cocos Creator **3.8.8**.
- Для повторной обработки ассетов: Python 3, Pillow и NumPy.

### Установка

```bash
git clone https://github.com/K8rvin/kotogorod-game.git
cd kotogorod-game
npm install
```

Скрипт `tools/cocos.mjs` ожидает редактор по пути `.cache/cocos/editor/CocosCreator.exe`. При другом расположении Cocos Creator измените значение `editor` в этом файле. Каталог `.cache/` намеренно не хранится в репозитории.

### Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Запустить проект через Cocos Creator. |
| `npm run typecheck` | Проверить типы в настроенной рабочей среде. |
| `npm run build` | Собрать Web Mobile-версию в `build/web-mobile-current/`. |
| `npm run preview` | Запустить локальный сервер собранной игры на порту 8080. |

Для другого порта задайте переменную окружения `PORT`, например в Git Bash:

```bash
PORT=8092 npm run preview
```

После запуска откройте `http://127.0.0.1:8080/` или адрес с выбранным портом.

## Структура

```text
assets/
  scenes/               Главная Cocos-сцена
  scripts/              Игровая логика, интерфейс, город, доска и звук
  resources/textures/   Игровые изображения и метаданные импорта
assets-src/generated/   Исходные сгенерированные изображения и метаданные
settings/               Настройки проекта Cocos Creator
tools/                  Сборка, локальный сервер и обработка ассетов
```

Основные точки входа:

- `assets/scripts/GameRoot.ts` — инициализация игры.
- `assets/scripts/core/state.ts` — состояние, сохранения, прогресс и режимы.
- `assets/scripts/data.ts` — предметы, персонажи, главы и процедурные истории.
- `assets/scripts/BoardController.ts` — доска, ввод и анимации.
- `assets/scripts/UIController.ts` — интерфейс и игровые экраны.

## Сохранения

Прогресс хранится в `localStorage` под ключом `kotogorod.profile.v3`; предыдущая версия сохранения дополнительно копируется в `kotogorod.profile.backup`. Временные доски дополнительных режимов не заменяют доску основной истории.

Начать заново можно через `Настройки → Начать историю заново`.

## Ассеты

Игровые ассеты уже находятся в репозитории. Инструменты в `tools/` позволяют заново разрезать листы, удалить фон и подготовить фоны:

```bash
python -m pip install pillow numpy
python tools/process_sheet.py --help
python tools/remove_background.py --help
python tools/process_background.py --help
```

## Интеграция с платформами

Текущая версия является самостоятельной браузерной игрой. Интеграция с Яндекс Играми, реклама и облачные сохранения намеренно не подключены и будут добавляться отдельным этапом.
